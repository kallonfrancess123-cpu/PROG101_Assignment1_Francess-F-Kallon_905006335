# CleanSalone SL - PROG101 Assignment

**Project:** A Community Waste Reporting and Collection Prioritisation System for Sierra Leone.

CleanSalone SL is a proposed logical-design solution for reporting and tracking visible waste incidents. It provides validation, duplicate linking, risk-based priority labels, specialist escalation for medical/hazardous waste, local route lookup, status tracking, and sample dashboard measures.

## Files
- `CleanSalone_SL_Assignment.docx` - editable report.
- `CleanSalone_SL_Assignment.pdf` - PDF report.
- `CleanSalone_SL_Flowchart.png` and `.pdf` - workflow diagram.
- `CleanSalone_SL_Pseudocode.md` - language-independent pseudocode.
- `CleanSalone_SL_Algorithm_and_Testing.md` - algorithm, thresholds and test plan.

## Important Scope Note
This package is a logical design proposal, not an implemented application. The assignment brief says students do not need to write source code. Priority thresholds and the 72-hour duplicate window are illustrative pilot settings, not official national standards. The system does not replace an approved waste collection service, make a technical determination about hazardous material, impose penalties or guarantee a collection date.

## Localisation and Safeguards
Before a real pilot, a participating local council must approve report categories, priority thresholds, privacy practices, response times and the directory of approved service providers/specialist contacts. Where the responsible route is unknown, the system must mark a report for manual routing. Personal contact details should be optional and access-restricted.
